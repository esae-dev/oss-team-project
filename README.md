# Mini Kiosk
(*커밋 로그로 확인해주세요!*)

#### oss-team-project / 최민서 & 박수성
Java 콘솔 기반 미니 키오스크 주문 프로그램입니다.
- 최민서: 기획 및 코드 구조 설계/개선

- 박수성: 기능 모듈 구현 및 유지보수

## 구상
1. (기본 기능) 메뉴를 보여주고, 사용자가 메뉴 번호와 수량을 입력하면 주문 내역과 총 금액을 출력합니다.
2. (1차 기능 확장) 영수증 출력, 입력 오류 처리 등 기본 편의 기능을 추가합니다.
3. (2차 기능 확장) 음료 hot/iced 옵션, 메뉴 food/drink 구분, 다중 주문 등 추가 기능을 확장합니다.
4. (기타) 추후 Food, Pizza, CheesePizza 등의 클래스를 만들어 업캐스팅, 오버라이딩 같은 Java 개념을 적용하여 추가로 제작합니다.

---

## 세부사항

### 기본 구조
- Menu.java : 메뉴 이름과 가격을 저장하고 메뉴판을 출력합니다.
- Order.java : 선택한 메뉴와 수량을 바탕으로 주문 내역과 금액을 계산합니다.
- Main.java : 프로그램을 실행하고 Menu와 Order를 연결합니다.

### 추가할 기능(1차)
1. Receipt.java : 영수증 - 주문 내역과 총 금액을 영수증 형태로 보기 좋게 출력합니다.
2. InputCheck.java : 입력 오류 처리 - 잘못된 입력을 처리합니다.

### 추가할 기능(2차)
3. Option.java : 음료 메뉴에 hot/iced 옵션을 추가합니다.
4. Category.java : 메뉴를 food, drink 등으로 구분합니다.

### 추가할 기능(3차)_객체 변환
5. MenuItem.java : 메뉴 이름과 가격을 하나의 객체로 분리
6. OrderItem.java : 주문한 메뉴/수량/합계 금액을 하나의 객체로 분리

*(컬렉션 활용해서 항목 더 깔끔하게 배치할 예정)*

### 추가할 기능(4차)_GUI 확장과 함께 추가(추후)
7. OptionManager.java : (음료일 때) 메뉴에 옵션 붙이기
8. PaymentManager.java : 결제 수단 목록 출력
9. DiscountManager.java : 할인 기능
